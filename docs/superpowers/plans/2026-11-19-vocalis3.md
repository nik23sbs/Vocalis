# Vocalis 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Neural on-grid vocal engine with Parlato/Rap/Canto, notes, variants, harmonies, 4-voice orb, macros, pronunciation editor, and the "Studio" GUI.

**Architecture:** A controllable Kokoro ONNX graph (dur/f0 overrides + f0 output) is driven by a new `TimingPlanner` (token-level durations from grid/notes) and `PitchPlanner` (F0 curve from natural f0, edits, notes, vibrato). The `Renderer` runs 2–3 model passes per voice, micro-aligns with a continuous WSOLA warp, renders harmony voices, and outputs a stereo clip with a preroll. The editor is rebuilt as layout A.

**Tech Stack:** C++17, JUCE 8.0.4, ONNX Runtime 1.23.2 (dynamic), Kokoro-82M, eSpeak-NG, WORLD, Python `onnx` for graph surgery in CI.

**Spec:** `docs/superpowers/specs/2026-11-19-vocalis3-design.md`

## Global Constraints
- Kokoro: 24 kHz, 600 samples per duration frame, 2 F0 values per frame; tokens ≤ 480 per chunk.
- Model file `kokoro-v1.0-ctrl.onnx` preferred, `kokoro-v1.0.onnx` accepted (no timing control → v2 path).
- macOS universal build, VST3/AU/Standalone; auval -strict and pluginval level 5 must pass in CI.
- Every UI string is in Italian.
- Audio thread: no allocations or locks except the existing SpinLock try-lock.

## Review Focus
- Very fast tempos (step shorter than the consonant cluster): durations are compressed, vowels keep ≥1 frame, anchors stay monotonic.
- Text longer than one chunk (>480 tokens): timing continues across chunks with no drift.
- Edits that make syllables overlap (shift backwards past the previous one): clamped, no crash.
- Canto with fewer notes than syllables / a MIDI file with chords: one note per syllable (highest note), extras cycle.
- Model missing or original model only: fallback to the v2 chain with a warning, never silence.
